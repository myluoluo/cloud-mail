# Cloud Mail 界面重设计

本次交付一个可运行方向：**信笺工作台**。用户每天来这里读邮件、切换域名邮箱、回复和写信；首屏的主角是邮件本身。保留现有路由、权限、邮件 API、Pocket ID 和写信编辑器。

## 方向卡

- 北极星：像把信件放在一张整洁的工作桌上，重要内容一眼可见，读信时不被工具打扰。
- 调性：安静、精致、中等密度、轻、偏庄重。邮件是高频文字工具，色块和动画只帮助定位。
- 生成引擎：信笺与文件夹；由纸面、分隔、抬头和留白组织内容，不搬入邮戳等道具。
- 品类标杆：[Fastmail](https://www.fastmail.com/)、[HEY](https://www.hey.com/)、[Proton Mail](https://proton.me/mail)。沿用工具导航和邮件列表的熟悉结构；不引入标杆的业务分类。
- Fastmail 取舍：文件夹导航让位置稳定、列表把发件人与主题对齐、选中只强调当前对象、写信保持可达、正文独立阅读、单一强调色控制注意力。保留这六个目的，换成更浅的纸面、更宽的阅读行距和青绿色识别；不用其品牌色与图形。
- 首屏骨架：200px 导航 + 220px 可折叠邮箱栏 + 邮件列表；80px 页头、52px 操作栏，首封邮件完整可见。阅读页直接把正文作为主内容。
- 字体：系统 sans-serif，中文 PingFang SC；页头 24px/600，主题 15px/600，正文 15px/1.8，辅助文字不小于 13px。
- 色板：纸面 `#ffffff`、环境 `#f5f7f8`、导航 `#eff3f2`、墨色 `#24342f`、次级 `#66736e`、青绿 `#237a65`、选中 `#e0eee8`；深色模式保留同一色相与层级。
- 主视觉：邮件排版本身。登录保留一个居中表单和产品名称，不依赖外部图片。
- 图标：复用现有本地图标；品牌标记为共享 SVG，避免在线图标请求。
- 控件：8–12px 圆角、1px 细线；主按钮纯色，其余工具中性；键盘焦点可见。
- 动效：主按钮按下 0.98 倍；侧栏与账户栏 240ms 平移；首次页面/登录内容 320ms 淡入，写信窗口 240ms 淡入。减少动态效果时立即到位。
- 结构性变化：原先互相分裂的深色导航、渐变标题、卡片邮箱改成连续的浅色工作区，正文有独立最大阅读宽度。
- 记忆点：云与信封的组合标记、安静的青绿选中状态；不增加装饰性指标、欢迎卡片或口号占据收件箱。
- 放弃：蓝色渐变、整屏漂浮云、多彩工具图标和重复卡片边框。

## 运行与验收边界

Docker 运行真实 Vue + Wrangler 本地 Worker、D1 和 KV。账户与种子邮件均为本地测试数据，初始化凭据由环境变量提供；未连接真实收发信、Cloudflare 生产数据或线上 Pocket ID。

检查桌面 1440×900、手机 390×844、登录/收件箱/阅读/设置/写信、深色模式与键盘焦点。截图、动效和独立视觉评审证据保存在 `shots/`（不提交生成文件）。

## 实际验收

以下为预览环境运行时的验收记录。2026-10-10 按用户要求清理临时容器、镜像和网络；保留测试数据卷及可重建环境的 Docker 配置。

- 验收时 Docker 中的前端与 Worker 运行在 `http://127.0.0.1:3001`。本地账号、十一封邮件、D1 与 KV 均实际创建，没有替换成 mock 接口。
- 从登录入口进入九封邮件的收件箱；在列表加载完成后切换工作邮箱，返回一封「十月项目进度与待办」；打开主邮箱的长邮件，正文、收件人和工具栏正常显示。

- `git diff --check`、两份 Docker 脚本的 Node 语法检查和 Compose 配置检查通过。未执行生产构建、提交、推送或生产部署。
