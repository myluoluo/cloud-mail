# 会话撤销边界

会话保存在 Workers KV 中。退出按令牌撤销当前会话；最后一个会话退出时删除记录，其余记录保留有限过期时间。密码修改会先删除该用户的会话记录，删除失败时不写入新密码；如果后续数据库更新失败，用户需要以原密码重新登录。

认证会在每日续期前检查记录期限，防止旧版本退出操作留下的永久 KV 记录恢复有效。自助改密成功后浏览器会清除令牌并返回登录页。

Workers KV 是最终一致存储，同一键的并发写采用后写覆盖。跨位置立即撤销，以及同一账号的并发登录、退出与改密之间的全局原子性，仍不在当前会话存储合同内；本次修复不提供这些保证。需要这些保证的部署应将会话状态迁移到支持原子更新的一致存储。[Workers KV 写入行为](https://developers.cloudflare.com/kv/api/write-key-value-pairs/)
